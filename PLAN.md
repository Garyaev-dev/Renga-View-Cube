# План улучшений ViewCubeOverlay

> **Разработчик:** Гаряев Иван Иванович. **Версия плагина: 1.5.2.**

## Итерация 4 (2026-09-11)

Встроенный навигационный куб Renga — нативный Qt UI (настройка `lbEnableNavigationCube` / «отображать навигационный куб»). В COM API v2.50 нет ViewCube/Compass: только `ICamera3D.LookAt` / `LookAtAnimated` и `LookAtSelectedObjects*` + `CameraOrientation` (26 направлений). Preset-методы меняют фокус на выбранное/сцену, поэтому клики куба по-прежнему через `LookAt` с сохранением дистанции. Механика CAD: грани+рёбра+углы, snap в орто, Home = изометрия TopFrontRight, подписи «Сверху/Спереди», hover, без кражи фокуса.

Добавлено: масштаб виджета 0.7–1.8 (колёсико, Ctrl не обязателен, кнопки +/− у Home), `CubeScale` в `settings.txt`; стили (цвета граней/подписей/маркеров, пресеты Классика / Нейтральный / Контраст, компактный заголовок) — окно ⚙ или ПКМ, live без перезапуска.

## Итерация 3 (2026-09-08)

- Куб с запасом вписывается в виджет (камера дальше, FOV 28°, без двойного top-margin Viewport).
- Подписи: Segoe UI Bold, белый текст + обводка + тёмная плашка; «Сверху» читается в изометрии TopFrontRight.
- Клик по граням: свой ray-pick (WPF HitTest 3D ломается при `AllowsTransparency`).
- Углы уменьшены; середины рёбер кликабельны.

## Проверка в Renga

- [ ] Включить куб → drag → перезапуск Renga → позиция та же
- [ ] Чертёж: кнопка disabled; 3D: enabled, окно возвращается
- [ ] Вид сверху — подсветка грани «Сверху»; изометрия — без active (или порог)
- [ ] Клик по грани / ребру / углу переключает вид; мелкое движение = клик, дальше = орбита
- [ ] Автопоказ не крадёт фокус у viewport
- [ ] ⟲ сбрасывает позицию
- [ ] Куб с полями: углы и рёбра не обрезаются рамкой
- [ ] «Сверху» читается в изометрии, подписи контрастные
- [ ] Колёсико / +/− меняют размер куба, позиция относительно Renga сохраняется
- [ ] ⚙ или ПКМ: пресет и цвета применяются сразу, после перезапуска те же

## Backlog / next features

Не предлагать как новое (уже сделано): Net8, события вида, `settings.txt`, масштаб 0.7–1.8, пресеты включая фасочный Renga, цвета, Home, рёбра/углы, UV-подписи, obfuscation/Release, stay-open пикер.

API-факт (v2.50): нет ViewCube/Compass/TrueNorth и нет выключателя нативного куба. Есть `LookAt` / `LookAtAnimated`, `LookAtSelectedObjects*` + 26 `CameraOrientation`, `ICamera3D.Projection`, `IModel.GetBoundingBox`, `IModelView.VisualStyle` / `ShowObjectsAnimated`, `IScreenshotService` с `IView`.

### P0 — сразу видно пользователю

| Возможность | Как | API |
|-------------|-----|-----|
| Стрелки поворота 90° вокруг видимой грани | 4 стрелки по периметру фронтальной грани (как AutoCAD ViewCube); клик крутит камеру вокруг оси взгляда / Z для «Сверху» | `LookAt` / `LookAtAnimated`, без нового SDK |
| Вписать в выбор / модель | Кнопка Fit рядом с Home; есть выбор → fit выбора, нет → вся сцена. **Не** подменять клики граней (фокус/дистанция должны сохраняться) | `LookAtSelectedObjectsAnimated` (пустое выделение = сцена); запасной путь: `IModel.GetBoundingBox` + `LookAt` с текущим направлением |
| Компас / север | Кольцо N/S/E/W под кубом, вращается вместе с видом. Истинного севера в API нет (`ISiteInfo` — только имя/адрес) | Визуал + опциональный угол смещения в `settings.txt` |
