Первый релиз плагина «Видовой куб» для Renga.

### Возможности
- Навигация по граням, рёбрам и углам куба; возврат к изометрическому виду.
- Настройка цветов, подписей, масштаба и положения окна с сохранением параметров.
- Обновлённое окно настроек и вкладка «О плагине» с версией и ссылкой на проект.

### Требования
Renga с API 2.48 или новее, поддержкой Net8 и .NET 8 для Windows x64.

### Установка
Закройте Renga, распакуйте архив и скопируйте файлы в папку Plugins\ViewCubeOverlay установленной Renga. Затем запустите Renga и откройте 3D-вид.

### Проверка
Release-сборка и автоматическая проверка окна настроек прошли. Интеграционная проверка этой сборки внутри Renga не проводилась.
